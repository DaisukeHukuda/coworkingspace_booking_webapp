## 1. 絶対に守る制約

1. **JavaScript を一切使わない。** サーバーレンダリング HTML ＋ 通常の `<form>` と `<a>` のみ。モーダル・ドラッグ・タブ切替・日付ピッカーの独自実装をしない。ホバー／フォーカス／`:target` など CSS の擬似クラスのみ可。
2. **CSS は 1 ファイル**（`/static/app.css` など）。CSS フレームワーク不使用。CSS 変数は使ってよい。`@media` は使ってよい。
3. **Web フォント禁止。** 下記のシステムフォントスタックのみ。
4. **状態を色だけで区別しない。** 必ず「色 ＋ 文字 ＋ 形」の三重で表す（後述）。
5. UI 文言はすべて日本語・丁寧語。**会員向け画面はあたたかい語り口、スタッフ画面は事務的・簡潔。**
6. 会員ページは幅 375px で快適に。**カレンダーの日付セルは最小 54px 角**（タップ領域 44px 以上を必ず確保）。
7. 絵文字を使わない。装飾は罫線・色面・ウェイトだけで行う。

## 3. 共通パーツ

### 3-1. 罫線ボックス（すべてのカード）
`border:1px solid var(--line); background:var(--canvas);` 影は使わない。
見出し行がある場合は `border-bottom:1px solid var(--line)` で仕切る。

### 3-2. ボタン
| 種類 | スタイル |
|---|---|
| 主（1 画面に 1 つ） | `background:var(--navy); color:#fff; padding:11px 22px;` hover `--navy-2` / active `--navy-ink` |
| 副 | `background:#fff; border:1px solid var(--navy); color:var(--navy);` hover は地を `#f2f4f8` |
| 危険（否認） | `background:#fff; border:1px solid var(--ng); color:var(--ng);` |
| 無効 | `background:var(--paper-3); color:var(--ink-4); cursor:not-allowed;` |

すべて `:focus-visible { box-shadow:var(--focus); outline:none; }`。会員ページの主ボタンは **高さ 48px 以上・横幅 100%**。

### 3-3. 状態バッジ（色＋文字＋形）

```
申請中  ○ 申請中   bg:--wait-bg  border:--wait-bd  color:--wait-fg
確定    ● 確定     bg:--ok-bg    border:--ok-bd    color:--ok-fg
否認    × 否認     bg:--ng-bg    border:--ng-bd    color:--ng-fg
キャンセル済み  − キャンセル済み  bg:--off-bg  border:--off-bd  color:--off-fg
```
`padding:3px 8px; border:1px solid; font:700 11.5px/1.6 var(--font-sans); letter-spacing:.04em;` 記号は 9px。

### 3-4. 種別バッジ
`月額会員` = `--type-m-*`／`回数券` = `--wait-*`。`padding:2px 8px; font:700 11px/1.5;`

### 3-5. メッセージ帯（成功／エラー）
画面最上部、ヘッダー直下に全幅で置く。
- 成功: 地 `--ok-bg` / 下罫 `#9dbfa6` / 丸い `✓` バッジ（18px, 地 `--ok`, 白字）
- エラー: 地 `--ng-bg` / 枠 `--ng-bd` / 角の `!` バッジ（16px 正方形, 地 `--ng`, 白字）
文字は `12.5px/1.7`。

## 4. 画面 1 ─ 会員ページ（最重要／375px）

縦順に：**ヘッダー → （メッセージ帯）→ 会員名 → 次回のご利用 → カレンダー → 凡例 → 入力フォーム → あなたのリクエスト → LINE 導線**

### 4-1. ヘッダー
`background:var(--navy); padding:13px 16px;` 左に `TORCH`（`900 19px`, `letter-spacing:.1em`, 白）＋ 直下に `COWORKING SPACE`（`8.5px var(--font-mono)`, `letter-spacing:.28em`, `rgba(255,255,255,.68)`）。右に `MEMBER / BOOKING`（`10px` mono, `rgba(255,255,255,.6)`, 右寄せ 2 行）。

### 4-2. 会員名ブロック（地は `--paper`, `padding:18px 16px 0`）
「こんにちは、」（13px, `--ink-2`）→ `田中 美咲 さま`（`900 22px`）＋ 種別バッジ → 回数券会員のみ `残り 8 回分`（mono 12px、数字だけ 15px/700/`--ink`）。
月額会員には残回数を出さない。

### 4-3. 次回のご利用（リボンカード）
`border:1px solid var(--line)`。
- 白いタイトルバー：左「次回のご利用」（`700 12px`, `.08em`）／右に `● 確定` のインライン表示。
- 本体：地 `var(--torch)`。`7月30日`（`900 25px`）＋`（木）`（16px）／`10:00 — 15:00`（mono `700 15px`, `.06em`）／一言（12px, `--ink-2`）「お待ちしております。当日は入口の灯りを目印にお越しください。」
- 確定予約が無いときはこのブロックごと出さない。

### 4-4. カレンダー
アイブロー `SELECT A DAY`。

**月ナビ**：`border:1px solid var(--line); background:#fff` の横並び。左右の `‹` `›` は幅 52px の `<a href="?ym=2026-06">`。中央に `2026年 7月`（`900 16px`）。

**グリッド**：`display:grid; grid-template-columns:repeat(7,1fr); gap:1px; background:#e2ded2; border:1px solid var(--line); border-top:0;`（gap が罫線に見える）。
曜日行は地 `--paper`、`700 11px`。日=`--ng`、土=`--cobalt`、他=`--ink-2`。

**日付セル**（高さ 54px・`position:relative`・中央寄せ・縦積み）

| 状態 | 地 | 数字色 | 追加 | 要素 |
|---|---|---|---|---|
| 選択可 | `#fff` | `--ink` | — | `<a href="?date=2026-07-31#form">` |
| 今日 | `#fff` | `--ink` | `box-shadow:inset 0 0 0 2px var(--navy)` | a |
| 選択中 | `--navy` | `#fff` | — | a（自分自身へ） |
| 過去・期間外 | `--paper-3` | `--ink-4` | — | `<span>`（リンクにしない） |
| 受付停止日 | `--paper-4` | `--ink-4` | 右上に `停`（`700 10.5px`, `#5a5f66`） | span, `aria-disabled` |
| 満席（Square） | `--paper-4` | `--ink-4` | 数字を上寄せ（`justify-content:flex-start; padding-top:5px`）にし、セル下部 31px に `×`（`300 27px`, `#5f646b`）を絶対配置。数字と重ねない | span, `aria-disabled` |

数字は `600 15px/1`。数字の下 3px に **自分の予約ドット**（8px 角）：

| 予約状態 | 形 |
|---|---|
| 申請中 | 円・地 `--paper`・`border:2px solid var(--wait)`（＝橙の輪） |
| 確定 | 円・塗り `--ok` |
| 否認 | **正方形**・塗り `--ng` |

同じ日に複数ある場合は「確定 > 申請中 > 否認」の優先で 1 つだけ表示。

**凡例**（カレンダー直下、`flex-wrap`, `gap:6px 14px`, 11px）
`○ 申請中` / `● 確定` / `■ 否認` / `停 ＝受付停止日` / `× ＝満席`
凡例のマークは実物と同じ形・同じ色で描く（停・× は 19×15px の枠付きボックスに `#5a5f66` の文字）。`停`・`×` は地 `--paper-4` に対して 4.5:1 以上のコントラストを確保すること（`#a7a294` では不足）。

### 4-5. 入力フォーム（`id="form"`）
**日付未選択のとき**：`border:1px dashed #b9b3a3; background:#fffdf7; padding:20px 16px;` 中央寄せで
「ご利用になりたい日を選んでください」（`700 13px`）＋「上のカレンダーで日付を押すと、時間の入力欄がここに開きます。」（12px, `--ink-3`）。

**日付選択後**：
- 紺のタイトルバー（`background:var(--navy); padding:11px 13px`）に `7月31日（金）のご利用`（`900 15px`, 白）
- 開始時刻 / 終了時刻 の `<select>` を 2 カラム（`gap:10px`）。高さ 46px、`border:1px solid var(--line)`、文字は mono 15px。選択肢は設定の受付時間帯から 30 分刻みで生成。
- 補足「9:00〜18:00 の間で、30分きざみでお選びいただけます。」（11px, `--ink-3`）
- `スタッフへのひとこと（任意）` の `<textarea>`（最小高 72px, 13.5px/1.8）
- 主ボタン「リクエストを送信する」（全幅・`padding:16px 0`・`900 15px`・`.08em`）
- 直下に「この時点ではまだ確定ではありません。／スタッフの確認後、メールでお知らせします。」（11px 中央）

**バリデーション（サーバー側で検証し、再描画で帯を出す）**
- 終了 ≤ 開始 → 「終了時刻は開始時刻より後の時間をお選びください。」
- 受付停止日・満席日・過去日・受付可能期間外 → 「その日は受け付けておりません。別の日をお選びください。」
- 同一会員・同一時間帯の重複 → 「同じ時間帯のリクエストがすでにあります。」

### 4-6. あなたのリクエスト
見出し（`900 16px`）＋ 右に件数（mono 11px）。カードを `gap:10px` で縦積み。
1 枚 = 上段（日時 `700 14px` ＋ 状態バッジ、下罫 `--line-2`）／下段（メモ 12px `--ink-3` ＋ 右に副ボタン）。
ボタンは 申請中・確定 →「キャンセル」、否認・キャンセル済み →「非表示にする」。
キャンセル済み行は日時を `--ink-4` に落とす。0 件なら「まだリクエストはありません。」

### 4-7. LINE 導線（最下部）
上罫 `--line-3` の後、中央寄せで「変更・キャンセルのご相談、その他ご質問は／LINE でお気軽にどうぞ。」＋ 全幅の副ボタン「LINE で問い合わせる」（`padding:14px 0`, `border:1px solid var(--line)`）。

## 14. アクセシビリティ

- 選択不可の日は `<a>` にしない（`<span aria-disabled="true">`）。`停`・`×` は `<span class="sr-only">受付停止日</span>` / `満席` を併記。
- 状態は必ず文字を伴う（バッジ内テキスト）。カレンダーのドットには `title` と視覚に頼らない凡例を用意。
- コントラストは AA 以上（`--ink-4 #a7a294` は無効表示にのみ使用）。
- フォーカスリングは `--focus` を全インタラクティブ要素に。
- 日曜=赤／土曜=青は色のみの情報ではないこと（曜日文字がある）。
